# Python Password Checker

A simple Python-based password strength checker.  
It evaluates passwords based on length, uppercase/lowercase letters, numbers, and special characters.

---

## Features
- Checks password length
- Ensures at least one uppercase letter
- Ensures at least one lowercase letter
- Ensures at least one number
- Ensures at least one special character
- Provides user-friendly feedback

---

## Technologies Used
- Python 3
- Regular expressions (regex)

---

## How to Run

```
# Clone the repository
git clone https://github.com/your-username/python-password-checker.git

# Go into the project folder
cd python-password-checker

# Run the script
python3 password_checker.py
```
